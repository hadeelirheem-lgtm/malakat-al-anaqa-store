# 👑 ملكة الأناقة — متجر أزياء وإكسسوارات

متجر إلكتروني متكامل باللغة العربية بأسلوب PHP + MySQL + Bootstrap، مصمّم ليعمل محلياً على **XAMPP** وهو جاهز للنشر.

## ✨ الميزات

- **العملاء:**
  - تسجيل دخول / إنشاء حساب / استعادة كلمة المرور عبر البريد
  - تصفح المنتجات والبحث والفلترة حسب الأقسام
  - صفحة تفاصيل المنتج
  - سلة تسوق (زيادة/نقصان/حذف) مع إجمالي وشحن
  - **المفضلة** — حفظ المنتجات وإضافتها للسلة بضغطة واحدة
  - أكواد خصم (عامة على السلة أو مرتبطة بمنتج محدد)
  - إتمام الطلب (دفع عند الاستلام / تحويل بنكي مع إرفاق إيصال)
  - فاتورة PDF/طباعة بعد الطلب
  - آراء العملاء ومنطقة إعادة التعليقات

- **لوحة الأدمن:**
  - إدارة المنتجات (إضافة/تعديل/أرشفة)
  - إدارة الطلبات وتغيير حالتها
  - إدارة أكواد الخصم
  - المنتجات المؤرشفة

## 🛠️ المتطلبات

- PHP 7.4+ (يُنصح 8.x)
- MySQL / MariaDB (XAMPP يوفّر الاثنين معاً)
- Composer (مطلوب فقط عند تثبيت الاعتماديات من الصفر)
- حساب Gmail مع **كلمة مرور تطبيق** لإرسال البريد

## 🚀 التشغيل محلياً (XAMPP)

1. انسخ مجلد المشروع إلى `C:\xampp\htdocs\` (يمكنك تسميته مثلاً `malakat-al-anaqa`).
2. شغّل **Apache** و **MySQL** من لوحة XAMPP.
3. أنشئ قاعدة البيانات بالهيكل:
   ```
   mysql -u root -p < sql/store.sql
   ```
   أو من **phpMyAdmin**: تبويب "استيراد" → اختيار `sql/store.sql`.
4. (اختياري) ثبّت الاعتماديات إذا كان مجلد `vendor/` غير موجود:
   ```
   composer install
   ```
5. افتح المتصفح على: `http://localhost/malakat-al-anaqa/` (أو باسم المجلد الذي اخترته).

> بيانات الاتصال الافتراضية (XAMPP): `localhost` / `root` / بلا كلمة مرور — يمكن تغييرها عبر متغيرات البيئة (انظر أدناه).

## 📧 إعداد البريد (اختياري لكن موصى به)

لتفعيل إرسال كلمة المرور الجديدة والرسائل:

1. فعّل **التحقق بخطوتين** في حساب Google الخاص بك.
2. أنشئ **كلمة مرور تطبيق** من: إعدادات Google → الأمان → كلمات مرور التطبيقات.
3. أنشئ ملف `mail_private.php` في جذر المشروع بالمحتوى التالي:
   ```php
   <?php
   return [
       'username' => 'your@gmail.com',
       'password' => 'your-app-password',
   ];
   ```
   > ⚠️ **لا ترفع هذا الملف إلى GitHub إطلاقاً** — وهو مستثنى بالفعpل في `.gitignore`.
   > بدلاً منه يمكنك أيضاً استخدام متغيرات البيئة: `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASS`.

## ⚙️ الإعدادات عبر متغيرات البيئة

| المتغير | الوصف | الافتراضي |
|----------|---------|----------|
| `DB_HOST` | عنوان قاعدة البيانات | `localhost` |
| `DB_NAME` | اسم القاعدة | `store` |
| `DB_USER` | مستخدم القاعدة | `root` |
| `DB_PASS` | كلمة مرور القاعدة | فارغة |
| `SMTP_HOST` | خادم البريد | `smtp.gmail.com` |
| `SMTP_PORT` | منفذ البريد | `587` |
| `SMTP_SECURE` | التشفير | `tls` |
| `SMTP_USER` | بريد المرسل | - |
| `SMTP_PASS` | كلمة مرور تطبيق Gmail | - |

## 🔐 ملاحظات أمنية

- كلمات المرور مخزّنة بتشفير `password_hash`.
- ملف `mail_private.php` **مستثنى من Git** ولا يجب مشاركته.
- مجلد `uploads/` محمي بـ `.htaccess` يمنع تنفيذ PHP.
- إدخالات المستخدم تُمرَّر عبر `htmlspecialchars` ومستعلمات مجهّزة (PDO).
